Home Board

Privacy policy

Last updated 9 October 2026

Home Board is a small dashboard that runs on a Raspberry Pi in a private home. It is not a hosted service. There is no company behind it, no server anyone else operates, and no account to sign up for. Each installation is a copy of open source code running on hardware owned by the person using it.

What is collected

Nothing is collected by the author of this software. No analytics, no telemetry, no crash reporting, no remote logging. The software never sends data to the author or to any third party that the person running it has not configured themselves.

What a board stores, and where

All of it stays on the Raspberry Pi it runs on:

  • Shopping list, notes, and events added on the board — plain JSON files in the installation's data/ folder.
  • A Google sign-in token, if a Google account has been connected — one file, data/google.json, written so only the account running the board can read it (mode 600). It is never sent to a browser, a phone, or anywhere off the device.
  • Per-screen preferences (theme, which widgets are shown) — in each browser's own local storage, on that device, never on the Pi.

Calendar events read from Google or from a subscribed calendar address are held in memory only, for as long as the board is running. They are never written to disk.

Google account data

Connecting a Google account is optional; the board works without one. When connected, it asks for two permissions:

  • calendar.readonly — to list the calendars on the account and read their events, so they can be shown on the board.
  • calendar.events — to create and delete events, which is what happens when someone adds or removes an event on the board itself.

That data is used only to draw the calendar on the board and on the phones of people in the same home. It is not copied anywhere else, not stored on disk, not sold, not shared, and not used for advertising, profiling, or training any model. Home Board's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Who can see it

Anyone who can reach the board on the home network — or on the private VPN it may be set up with — can read and change the shopping list, the notes, and the calendar. That is the point of it: it is a shared board for a household. It has no passwords and no separate accounts, so access is controlled entirely by who can reach the device. Whoever installs it decides that.

Where the board connects out to

  • Google — only if an account is connected, or a Google calendar address is subscribed to.
  • Open-Meteo — for the weather forecast, if a location is configured. No account, no identifiers; just coordinates.
  • Any calendar addresses the owner has added to the configuration.
  • Google Fonts — the browser loads two typefaces. This is the one request not under the board's control, and it can be removed by self-hosting the fonts.

Removing it

Disconnect Google in the board's Calendar app deletes the stored token immediately. Access can also be revoked from your Google account's permissions page, which works even if the device is gone. Deleting the data/ folder removes everything else; nothing survives it, because nothing was stored anywhere else.

Children

Home Board is not directed at children and asks for no personal information from anyone.

Changes

Any change to this policy is a commit in the public repository, with its history. The date at the top says when it last changed.

Contact
